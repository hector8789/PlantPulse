# PlantPulse Web

Frontend de PlantPulse: React 19 + TypeScript + Vite. Consulta el [README principal](../README.md) para la descripción completa.

```bash
cp .env.example .env.local   # VITE_API_URL=https://localhost:7177/api
npm install
npm run dev     # http://localhost:5173
npm test        # Vitest + Testing Library
npm run build
```
